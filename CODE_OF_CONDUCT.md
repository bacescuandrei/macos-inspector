# Code of conduct

This project welcomes technical discussion, bug reports, documentation work, and code contributions from people with different backgrounds and levels of experience.

Keep discussions respectful and focused on the work. Do not harass people, publish private information, use discriminatory language, or disrupt project spaces. Security evidence and incident data must be sanitized before they are shared.

Maintainers may edit or remove content that breaks these rules. Repeated or serious misconduct may result in a temporary or permanent ban from project spaces.

When disagreement occurs, explain the technical risk, evidence, and tradeoff. Attack the problem, not the person.
