LOCAL HTML DASHBOARD

Start macOS Inspector

The dashboard runs on your Mac and opens in your browser. This page is setup help, not the running application.

1. Check the runtime

You need macOS and Python 3.10 or newer. If Python is missing, use the official macOS installer, then reopen the launcher. The launcher checks available Python installations and does not download or install anything.

Official Python installers for macOS

Installing Python changes your Mac. Review the installer and its source before proceeding.

2. Open the application

  1. Extract the complete release ZIP. Keep this folder and its files together.
  2. In Finder, double-click macOS Inspector.command.
  3. Keep its launcher window open while using the dashboard.

The launcher opens http://127.0.0.1:8765/ after the local server is ready. Opening src/macos_inspector/webui/index.html directly cannot run scans.

This source distribution is not Apple-signed or notarized. Do not disable Gatekeeper globally. See installation guidance for verifying a release and resolving launch restrictions.

3. Check this Mac

Use Check this Mac for the guided workflow. Start with applications needing review and read the evidence before making changes. An unfamiliar application or incomplete verification is not automatically malware.

Core local scans need no third-party Python packages. Encryption and Ed25519 signing need the optional cryptography package; YARA needs its optional executable. The dashboard shows which features are available and why others are unavailable.

Online intelligence is opt-in. Reports, investigation notes, and action history stay in the selected local output directory.

If the dashboard does not open

Check the error in the launcher window. If you configured MACOS_INSPECTOR_PYTHON, it must identify a compatible executable; an invalid explicit override is not silently replaced. Details are in the private dashboard log under the release folder's tmp directory unless you selected another location.
